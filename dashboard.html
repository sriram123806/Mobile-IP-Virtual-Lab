Core Mobile IP Concepts

Ten fundamental principles of agent-based tunneling and transparent mobility.

1

What is Mobile IP?

Mobile IP (RFC 5944) is a standard network protocol that allows mobile device users to roam between different networks without altering their permanent IP address, preserving all active network connections and application sessions.

2

What is a Mobile Node?

A Mobile Node (MN) is any host or router (such as a smartphone, laptop, or moving vehicle) that changes its physical point of network attachment while continuously maintaining its permanent Home Address.

3

What is a Correspondent Node?

A Correspondent Node (CN) is the communication partner (such as a remote web server or streaming peer) that sends packets to the Mobile Node. The CN operates normally with zero knowledge of the Mobile Node’s physical location.

4

What is a Home Agent?

A Home Agent (HA) is a specialized router on the Mobile Node's permanent home network. While the Mobile Node is away, the HA intercepts incoming packets via Proxy ARP and tunnels them forward to the Mobile Node's current location.

5

What is a Foreign Agent?

A Foreign Agent (FA) is a router on the visited network that assists the roaming Mobile Node. It provides a Care-of Address, terminates the forward tunnel, decapsulates received packets, and delivers them locally to the MN.

6

What is a Care-of Address?

A Care-of Address (CoA) is a temporary IP address that identifies the Mobile Node's current point of attachment in a foreign network. The Home Agent uses this address as the destination for the tunneled outer IP header.

7

What is tunneling?

Tunneling is the method of encapsulating an entire original IP packet inside another outer IP packet so that it can be routed across the Internet to the Care-of Address without altering the original packet's headers.

8

What is encapsulation?

Encapsulation is performed by the Home Agent by adding a new Outer IP Header (Source: HA, Destination: CoA) around the intact original IP packet. The original packet remains completely unchanged inside.

9

What is decapsulation?

Decapsulation is the reverse process executed at the Foreign Agent where the outer IP header is stripped off, recovering the original IP datagram so it can be delivered over the local link to the Mobile Node.

10

How does packet delivery work in Mobile IP?

The Correspondent Node sends packets to the MN’s Home Address. The Home Agent intercepts them, looks up the registered Care-of Address, encapsulates the packet in a new outer header, and routes it through a forward tunnel to the Foreign Agent. The FA decapsulates the packet and delivers the original datagram over the local link to the Mobile Node.

Simulation Sequence

Step 1

Packet Generation

The Correspondent Node generates an original IP packet addressed to the Mobile Node's permanent Home Address.

Step 2

Home Agent Interception

The Home Agent intercepts the packet on the home network and confirms the Mobile Node is currently away from home.

Step 3

Encapsulation

The Home Agent wraps the original packet inside an outer IP header addressed to the Care-of Address.

Step 4

Forward Tunnel

The encapsulated packet traverses the IP-in-IP tunnel across South India from Home Agent to Foreign Agent.

Step 5

Decapsulation

The Foreign Agent strips off the outer IP header and recovers the pristine original IP packet.

Step 6

Final Delivery

The Foreign Agent delivers the original packet to the Mobile Node and confirms delivery to the Home Agent.

Mobile IP Failure Scenarios

Five essential operational breakdowns and diagnostic recovery workflows.

CASE 1

Home Agent Cannot Find the Mobile Node

The Correspondent Node sends packets, but the Home Agent has no valid Care-of Address in its binding cache.

CASE 2

Foreign Agent Registration Failure

The Mobile Node connects to a foreign network, but the Foreign Agent fails to relay the registration to the Home Agent.

CASE 3

Encapsulation Failure at Home Agent

Adding the outer IP header causes the datagram to exceed the Path Maximum Transmission Unit (MTU) with DF bit set.

CASE 4

Decapsulation Failure at Foreign Agent

The encapsulated packet arrives at the Foreign Agent, but header checksum validation or protocol parsing fails.

CASE 5

Mobile Node Changes Network During Transmission

While encapsulated packets are in flight through the tunnel, the Mobile Node abruptly roams to another foreign network.
