# Mobile IPv4 Scope and Standards Status

> Starter notes drafted by an AI assistant from the public Mobile IPv4 RFCs and standard networking textbook knowledge. Not lecturer material: replace or supplement with your own course notes.

## What this knowledge base covers
Everything in the Mobile IP folder describes **Mobile IPv4**. Do not apply it to Mobile IPv6.

## Standards
- **RFC 5944** is the revised Mobile IPv4 specification (IP Mobility Support for IPv4, Revised). It supersedes RFC 3344.
- **RFC 3344** is the earlier specification. It is a historical reference now: obsoleted by RFC 5944.
- **RFC 2003** defines IP encapsulation within IP (IP-in-IP).
- **RFC 3024** defines reverse tunneling for Mobile IP.

## How Mobile IPv6 differs (high level only)
Mobile IPv6 is a separate protocol with a different design. For example, it has no foreign agents, and it handles route optimisation and signalling differently. These notes do not describe its mechanisms; do not mix its terms with the Mobile IPv4 terms used here.
