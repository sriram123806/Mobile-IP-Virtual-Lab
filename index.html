About This Project

This virtual laboratory demonstrates how Mobile IP maintains seamless communication when a mobile device moves between networks. It explains Home Agent and Foreign Agent operations through encapsulation, tunneling and decapsulation using an interactive simulation with a Tamil Nadu map, real ASCII binary conversion, animated packet-flow visualisation and comprehensive theory content.

Built as a final university Data Communications & Networking project, this site covers Mobile IPv4 (RFC 5944), IP-in-IP tunneling (RFC 2003) and reverse tunneling (RFC 3024).
