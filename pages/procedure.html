PROCEDURE

Step-by-step operating instructions for the Mobile IP Virtual Laboratory

Step-by-Step Instructions

  1. 1

    Open the Simulation Page

    Navigate to the Simulation tab from the main horizontal navigation bar.

  2. 2

    Select Correspondent Node Location

    Choose the CN location (origin of data packets) from the location dropdown selector.

  3. 3

    Select Home Agent Location

    Choose the HA location (home network where the Mobile Node is originally registered) from the dropdown selector.

  4. 4

    Select Foreign Agent Location

    Choose the FA location (visited network where the Mobile Node is currently roaming) from the dropdown selector.

  5. 5

    Confirm Selected Locations

    Click the location OK button and verify that all three distinct node markers and route lines appear on the Tamil Nadu map.

  6. 6

    Enter a Transmission Message

    Type your alphanumeric message (up to 40 characters) into the ASCII message input field.

  7. 7

    Press OK to Convert

    Click the message OK button to encode the text into its standard 8-bit ASCII binary representation.

  8. 8

    Check Binary Representation

    Inspect the generated binary bit stream and verify each character's 8-bit sequence and byte length.

  9. 9

    Start the Simulation

    Click the START button to initiate the live packet animation and signal wave generation.

  10. 10

    Observe Packet Generation at CN

    Watch the original IP packet form at the Correspondent Node addressed to the Mobile Node's home address.

  11. 11

    Observe Packet Interception at HA

    See the Home Agent intercept the packet using proxy ARP and look up the Care-of Address in its binding table.

  12. 12

    Observe Forward Tunnel Transmission

    Watch the encapsulated IP-in-IP datagram travel across intermediate routers to the Foreign Agent.

  13. 13

    Observe Decapsulation at FA

    Witness the Foreign Agent strip the outer header and recover the pristine inner datagram.

  14. 14

    Observe Final Delivery to Mobile Node

    Confirm the final delivery of the datagram to the Mobile Node over the visited local link.
