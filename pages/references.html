REFERENCES

Official Standards, Authoritative Textbooks & Academic Learning Resources

1. Official RFC Standards

RFC 5944 — IP Mobility Support for IPv4, Revised

The core IETF standard specifying Mobile IPv4 entity operations, agent discovery, registration handshake, care-of addresses, and packet tunneling mechanisms. (Obsoletes RFC 3344 & RFC 3220)

RFC 2003 — IP Encapsulation within IP

Defines the IP-in-IP encapsulation protocol (IP Protocol 4), specifying how outer IP headers are constructed by the Home Agent and decapsulated by the Foreign Agent.

RFC 3024 — Reverse Tunneling for Mobile IP, Revised

Specifies reverse tunneling from the visited network back through the Home Agent toward Correspondent Nodes, preventing packet drops by edge router ingress filtering.

RFC 3220 — IP Mobility Support for IPv4

Foundational predecessor specification defining agent advertisement extensions, authentication extensions, and mobility binding maintenance.

2. Networking Textbooks

Computer Networks (5th Edition) — Andrew S. Tanenbaum & David J. Wetherall (Pearson)

Chapter 5 (The Network Layer): Provides comprehensive architectural analysis of network-layer mobility, routing for mobile hosts, and home agent binding tables.

Data Communications and Networking (5th Edition) — Behrouz A. Forouzan (McGraw-Hill)

Chapters 19 & 22: Covers network addressing, agent discovery, registration request/reply handshakes, and forward tunneling packet transformations.

Computer Networking: A Top-Down Approach (8th Edition) — James Kurose & Keith Ross (Pearson)

Chapter 6 (Wireless and Mobile Networks): Explains mobility principles, addressing and routing to mobile nodes, triangle routing overhead, and direct routing comparisons.

3. Educational Resources

Cisco Systems — IP Mobility: Mobile IPv4 Configuration Guide

Technical deployment guide documenting Home Agent configuration, Foreign Agent services, and mobility binding verification on production routers.

IETF — Mobility for IPv4 (mip4) Working Group

Official IETF archive containing charter documents, draft revisions, security considerations, and errata for IPv4 mobility standards.

Wikipedia — Mobile IP Architecture & Taxonomy

Collaborative reference summarizing agent roles, registration flow diagrams, care-of address classification, and evolution to Mobile IPv6.

RFC Editor — Official Internet Standards Repository

Official searchable index for all published Requests for Comments defining core protocols of the Internet Protocol suite.
