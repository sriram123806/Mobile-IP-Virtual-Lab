References

Official standards, textbooks, educational resources and project links for the Mobile IP Virtual Laboratory.

Official RFC Standards

RFC 5944 — IP Mobility Support for IPv4, Revised

The updated Mobile IPv4 standard defining agents, registration, care-of addresses and tunneling. Obsoletes RFC 3344.

RFC 2003 — IP Encapsulation within IP

Defines IP-in-IP (protocol number 4) encapsulation and decapsulation, used by the HA-to-FA tunnel.

RFC 3024 — Reverse Tunneling for Mobile IP, Revised

Describes reverse tunneling from the care-of address back through the Home Agent toward the Correspondent Node.

Networking Textbooks

Computer Networks — Andrew S. Tanenbaum & David J. Wetherall

Covers network-layer mobility concepts including Mobile IP, tunneling and address management. (5th edition, Pearson)

Data Communications and Networking — Behrouz A. Forouzan

Introductory text covering IP routing, mobile IP architecture and care-of address registration. (5th edition, McGraw-Hill)

Computer Networking: A Top-Down Approach — James Kurose & Keith Ross

Explains mobility at the network layer, agent discovery, registration and tunneling in the context of modern networking.
