SUMMARY

Mobile IP enables a mobile node to change its point of attachment from one network to another without altering its assigned home IP address. This location independence ensures that active transport-layer connections, such as TCP sessions and real-time streaming, continue uninterrupted during movement.

The packet delivery workflow follows a structured sequence: When a Correspondent Node (CN) transmits packets addressed to the Mobile Node (MN), the datagrams route to the home network. The Home Agent (HA) intercepts the packets using proxy ARP, encapsulates the original datagram inside an outer IP datagram (IP-in-IP, protocol 4) addressed to the Care-of Address (CoA), and sends it across the tunnel. At the tunnel endpoint, the Foreign Agent (FA) decapsulates the packet by stripping the outer IP header and delivers the original datagram directly to the Mobile Node: CN → HA (encapsulates) → tunnel → FA (decapsulates) → MN.

KEY CONCEPTS

Mobile Node (MN)

A device that can move between networks while keeping the same IP address. It registers with the Foreign Agent when visiting a new network.

Correspondent Node (CN)

Any host that communicates with the Mobile Node. It sends packets to the MN's home address without needing to know its current location.

Home Agent (HA)

A router on the MN's home network. Intercepts packets for the MN and tunnels them to the current location using IP-in-IP encapsulation.

Foreign Agent (FA)

A router on the visited network. Provides routing services to the MN and relays registration messages between the MN and the Home Agent.

Care-of Address (CoA)

The temporary IP address used by the MN in a foreign network — usually the FA's address. It serves as the tunnel endpoint for packets from the HA.

Encapsulation

Wrapping the original IP packet inside a new outer IP header to route it through the tunnel from the HA to the FA at the CoA.

Decapsulation

Removing the outer IP header at the FA to recover and deliver the original packet to the Mobile Node on the foreign network.

STUDY CASES

Case 1

Home Agent Cannot Find the Mobile Node

Packets reach the home network but the HA has no valid mobility binding for the MN, so it cannot tunnel them.

Case 2

Foreign Agent Registration Failure

The MN is in a foreign network but the FA does not relay its Registration Request, so the HA never learns the care-of address.

Case 3

Encapsulation Failure at Home Agent

The HA intercepts the packet but cannot build or send the IP-in-IP packet, so nothing enters the tunnel.

Case 4

Decapsulation Failure at Foreign Agent

Tunneled packets arrive at the FA but the original datagram is never delivered to the MN.

Case 5

Mobile Node Changes Network During Transmission

The MN moves to a new foreign network mid-transfer, so packets tunneled to the old CoA are lost.
