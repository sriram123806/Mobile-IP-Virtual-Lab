Summary

Mobile IP (RFC 5944) enables transparent mobility across heterogeneous networks by separating a host's permanent network identity (Home Address) from its physical point of attachment (Care-of Address). This ensures continuous transport-layer sessions, active socket states, and TCP throughput without disconnection during handoffs.

The standard packet workflow follows a clear sequence: Correspondent Node (CN) → Home Agent (HA intercepts via Proxy ARP and encapsulates) → IP-in-IP Tunnel (Protocol 4) → Foreign Agent (FA decapsulates) → Mobile Node (MN receives original datagram). For outbound traffic, Reverse Tunneling routes packets back through the HA to satisfy network edge ingress filtering.

Key Concepts

Core terminology and definitions required for Mobile IP evaluation:

1. Mobile Node (MN) A host or router that can change its point of attachment from one network to another while preserving its permanent Home Address.
2. Correspondent Node (CN) A peer device or server communicating with the Mobile Node by sending standard IP datagrams to the MN's permanent Home Address.
3. Home Agent (HA) A router on the Mobile Node's home network that intercepts incoming packets via Proxy ARP when the MN is roaming and tunnels them to the CoA.
4. Foreign Agent (FA) A router on the visited foreign network that provides Care-of Address services and decapsulates tunneled packets for local delivery to the MN.
5. Care-of Address (CoA) The temporary IP address assigned to the MN on a foreign visited network serving as the egress endpoint of the IP-in-IP tunnel.
6. Encapsulation The mechanism performed by the Home Agent of prepending a new 20-byte outer IP header (IP-in-IP, Protocol 4) to route the datagram across intermediate networks.
7. Decapsulation The mechanism performed by the Foreign Agent of stripping the outer IP header to recover and forward the original datagram directly to the Mobile Node.
