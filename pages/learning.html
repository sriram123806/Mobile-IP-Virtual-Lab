Summary

Mobile IP (RFC 5944) enables transparent mobility across heterogeneous networks by separating a host's permanent network identity (Home Address) from its physical point of attachment (Care-of Address). This ensures continuous transport-layer sessions, active socket states, and TCP throughput without disconnection during handoffs.

The standard packet workflow follows a clear sequence: Correspondent Node (CN) → Home Agent (HA intercepts via Proxy ARP and encapsulates) → IP-in-IP Tunnel (Protocol 4) → Foreign Agent (FA decapsulates) → Mobile Node (MN receives original datagram). For outbound traffic, Reverse Tunneling routes packets back through the HA to satisfy network edge ingress filtering.

Key Concepts

Core terminology and definitions required for Mobile IP evaluation:

Mobile Node (MN)

A host or router that can change its point of attachment from one network to another while preserving its permanent Home Address.

Correspondent Node (CN)

A peer device or server that communicates with the Mobile Node, sending standard IP datagrams to the MN's permanent Home Address.

Home Agent (HA)

A router situated on the Mobile Node's home network that intercepts incoming packets when the MN is roaming and tunnels them to the CoA.

Foreign Agent (FA)

A router on the visited network that advertises mobility services, provides a Care-of Address, and decapsulates tunneled packets for the MN.

Care-of Address (CoA)

The temporary IP address assigned to the MN on a foreign network (typically the FA's address) serving as the tunnel exit point.

Encapsulation

The process performed by the HA of wrapping the original IP datagram inside a new 20-byte outer IP header (IP-in-IP, Protocol 4).

Decapsulation

The process performed by the FA of stripping off the outer IP header to recover and deliver the original datagram to the Mobile Node.

Troubleshooting Study Cases

Click VIEW on any study case below to open its dedicated full-screen diagnostic flowchart, troubleshooting checklist, and resolution guide:

Case 1

Home Agent Cannot Find Mobile Node

Packets reach the home network, but the HA has no valid mobility binding for the MN, causing datagrams to be dropped or misrouted.

Case 2

Foreign Agent Registration Failure

The MN attempts attachment in a foreign network, but the FA refuses or fails to relay registration, preventing Care-of Address binding.

Case 3

Encapsulation Failure at Home Agent

The HA successfully intercepts the datagram but fails to construct or transmit the outer IP-in-IP tunnel packet toward the CoA.

Case 4

Decapsulation Failure at Foreign Agent

Tunneled packets arrive at the FA, but the outer header cannot be stripped or visitor list validation fails, dropping the inner datagram.

Case 5

Mobile Node Moves During Transmission

The MN transitions between foreign links mid-transfer while packets are in flight, causing packets sent to the old CoA to be lost.
